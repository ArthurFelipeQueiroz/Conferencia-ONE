Ativar a conexão com o banco

As páginas e o acesso da equipe ficam no GitHub do Arthur. O banco permanece na conta Cloudflare do Gustavo.

1. Abrir o Worker existente

No Cloudflare, abra conferencia-one-checkin. Em Configurações → Builds, desconecte o repositório ENRAIZADOS deste Worker. O código desta instalação está no repositório ArthurFelipeQueiroz/Conferencia-ONE.

2. Publicar a API

Clique no botão abaixo. No Cloudflare, abra Editar código, substitua o arquivo principal pelo código copiado e clique em Deploy / Implantar.

Baixar código

3. Conferir o vínculo com o banco

Em Bindings / Vinculações, a variável DB deve apontar para conferencia-one-2026, o banco já criado na conta do Gustavo.

4. Configurar o primeiro administrador

Gere o token abaixo. No Worker, abra Configurações → Variáveis e segredos e adicione um Secret chamado BOOTSTRAP_TOKEN. Cole o token no valor e clique em Salvar e implantar.

Mantenha esta página aberta. No painel da equipe, use esse mesmo token e escolha seu usuário e uma senha de pelo menos 12 caracteres. Após criar o administrador e conseguir entrar, remova o segredo BOOTSTRAP_TOKEN no Cloudflare.
