# Guia de operação — Conferência ONE, 7/11/2026

O painel público é publicado pelo GitHub do Arthur. A API e o D1 permanecem na Cloudflare do Gustavo.

1. Siga o README para ativar GitHub Pages e publicar a API pelo guia de instalação.
2. Crie o primeiro administrador pelo painel da equipe e remova o token temporário.
3. Importe somente os inscritos da Conferência ONE, sem enviar dados pessoais ao GitHub.
4. Crie os acessos dos operadores de recepção e teste o fluxo em dois celulares.
5. A chegada pelo participante não libera a entrada: a equipe confere a inscrição e registra a liberação.
6. Utilize o painel administrativo para relatórios e exportações privadas.
7. Camisetas, brindes e WhatsApp automático herdados do ENRAIZADOS permanecem desativados na API.
