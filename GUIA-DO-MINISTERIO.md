# Guia de operação — Conferência ONE, 7/11/2026

1. Criar GitHub privado e Cloudflare próprios, D1 novo, administrador novo e operadores de recepção.
2. Importar dados do novo evento usando o conversor local; não usar dados reais do ENRAIZADOS.
3. Testar antes do evento: abrir QR público, localizar cadastro, confirmar chegada e liberar entrada em /equipe. A chegada pelo participante não libera a entrada automaticamente.
4. Testar no mínimo dois celulares e a exportação dos dados; entregar acessos por canal privado.
5. Módulos de camisetas, prêmios e Evolution API estão desabilitados; não fazem parte do novo fluxo.
6. Dados de menores: seguir autorizações e política de retenção da organização. Remover acessos desnecessários após o evento.
