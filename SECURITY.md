# Segurança

Nenhum cadastro, login, D1, secret ou conector do evento ENRAIZADOS deve ser reutilizado. Nunca publique planilhas, JSON com participantes, QR individuais, backups de banco, tokens ou chaves. O Worker e D1 devem pertencer à conta do equipe da Conferência ONE. Cumpra a LGPD especialmente para dados de menores.
